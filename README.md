## Post a log

The easy way: go to <https://app.pagescms.org>, open this repo, choose **Logs**, then add a log. Drag in pictures as you write, and save. It appears on the site within a minute or two.

To add one by hand instead:

Add a Markdown file to [`_posts/`](_posts), named `YYYY-MM-DD-some-title.md`:

```markdown
---
title: Some title
---

Whatever is on your mind.
```

Commit it to `main`, and it appears on the site within a minute or two. The newest log shows first.

You can do this from github.com: open `_posts/`, then choose **Add file > Create new file**.
